# Autumn Salon – Website Redesign (UI/UX Case Study)

This repository contains my solution for **UI/UX Design Task 1 (2026)** by **Future Interns**.  
The brief was to redesign a local service business website with a strong focus on **lead generation and conversion optimisation**.

I chose **Autumn Salon**, a multi‑branch beauty salon in Hyderabad, and designed a **mobile‑first, conversion‑driven website** covering:

- Homepage
- Services page
- Booking page
- Contact page

## 🔍 Problem

Most local salon websites:

- Do not clearly explain their services
- Hide or weaken the “Book Now” action
- Give no pricing hints or trust signals
- Perform poorly on mobile devices

My goal was to design for a **business outcome**: more visitors turning into actual bookings.

## 🎯 Objectives

- Clearly communicate Autumn Salon’s services and positioning  
- Build trust with first‑time visitors using social proof and content  
- Make it extremely easy to **book, call or text** from any page  
- Improve mobile usability and follow key WCAG 2.1 accessibility ideas
